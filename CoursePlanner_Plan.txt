## 🗄️ Updated Database Models

### __1. User__

```javascript
{
  username: String (required, unique)
  email: String (required, unique, lowercase)
  password: String (required, hashed with bcrypt)
  isVerified: Boolean (default: false)
  verificationToken: String
  avatar: String (optional URL)
  createdAt: Date
}
```

### __2. Semester__

```javascript
{
  owner: Ref → User (required)
  name: String (e.g., "Fall 2025", required)
  startDate: Date
  endDate: Date
  isActive: Boolean (default: false)
  createdAt: Date
}
```

### __3. Course__

```javascript
{
  semester: Ref → Semester (required)
  owner: Ref → User (required)
  title: String (required)
  code: String (required, e.g., "CS101")
  credits: Number (required, min: 0)
  description: String
  instructor: String
  color: String (hex, for UI color coding)
  createdAt: Date
  updatedAt: Date
}
```

### __4. Deliverable__

```javascript
{
  course: Ref → Course (required, ref populate)
  type: Enum [quiz, assignment, exam, project, presentation]
  title: String (required)
  dueDate: Date (required)
  weight: Number (optional, percentage or points)
  description: String
  isCompleted: Boolean (default: false)
  createdAt: Date
}
```

### __5. ScheduleSlot__

```javascript
{
  course: Ref → Course (required, ref populate)
  owner: Ref → User (required)
  daysOfWeek: Array<String> (e.g., ["Mon", "Wed", "Fri"])
  startTime: String (24h format, e.g., "09:00")
  endTime: String (24h format, e.g., "10:30")
  recurring: Boolean (default: true, weekly)
  createdAt: Date
}
```


Auth Flow (with Email Verification)

Client                          Server                          DB
  │                              │                              │
  │  POST /api/auth/register     │                              │
  │  { username, email, pass }──>│                              │
  │                              │──→ hash pw + create user──>│
  │                              │    isVerified=false          │
  │                              │    generate verification     │
  │                              │    token                     │
  │                              │    → send verification email │
  │                              │    via Nodemailer            │
  │  ← { message: "Check email",  │                              │
  │     userId }                 │                              │
  │                              │                              │
  │  GET /api/auth/verify/:token │                              │
  │  (clicked from email)───────>│                              │
  │                              │──→ find user by token ─────>│
  │                              │    set isVerified=true       │
  │                              │    delete verificationToken  │
  │  ← { message: "Verified!" }  │                              │
  │                              │                              │
  │  POST /api/auth/login        │                              │
  │  { email, pass }───────────>│                              │
  │                              │──→ verify pw ──────────────>│
  │  ← JWT token + user ────────│                              │
  │                              │                              │
  │  Protected routes include    │                              │
  │  Authorization: Bearer <jwt> │                              │
📋 API Endpoints (Final)
Auth
Method	Endpoint	Description
POST	/api/auth/register	Register user + send verification email
GET	/api/auth/verify/:token	Verify email
POST	/api/auth/login	Login → JWT
GET	/api/auth/me	Get current user (protected)
PUT	/api/auth/update-password	Change password (protected)
Semesters
Method	Endpoint	Description
POST	/api/semesters	Create semester
GET	/api/semesters	List user's semesters
GET	/api/semesters/:id	Get semester detail
PUT	/api/semesters/:id	Update semester
DELETE	/api/semesters/:id	Delete semester
PUT	/api/semesters/:id/activate	Set as active
Courses
Method	Endpoint	Description
POST	/api/courses	Create course (under a semester)
GET	/api/courses	List all courses (filter by semester)
GET	/api/courses/:id	Get single course
PUT	/api/courses/:id	Update course
DELETE	/api/courses/:id	Delete course (cascades deliverables + slots)
Deliverables
Method	Endpoint	Description
POST	/api/courses/:courseId/deliverables	Add deliverable
GET	/api/courses/:courseId/deliverables	List (sorted by dueDate asc)
PUT	/api/courses/:courseId/deliverables/:id	Update
PUT	/api/courses/:courseId/deliverables/:id/complete	Toggle complete
DELETE	/api/courses/:courseId/deliverables/:id	Delete
Schedule
Method	Endpoint	Description
POST	/api/courses/:courseId/schedule	Add time slot
GET	/api/courses/:courseId/schedule	List slots
PUT	/api/courses/:courseId/schedule/:id	Update slot
DELETE	/api/courses/:courseId/schedule/:id	Delete slot
GET	/api/schedule/conflicts?semesterId=	Check all conflicts for active semester

Milestone 2 — Semesters + Course CRUD

Milestone 3 — Deliverables
 Deliverable model
 Deliverable API routes (CRUD + complete toggle)
 Frontend: Deliverable form, list (sorted by due date), checkbox for complete

Milestone 4 — Weekly Timetable
 ScheduleSlot model
 Schedule API routes + conflict detection
 Frontend: Weekly timetable grid (Mon–Fri or Mon–Sun)

Milestone 5 — Polish + Deploy

 GitHub Actions workflow: build + deploy to gh-pages on main push

 Test full flow: register → verify → login → create semester → add courses → schedule → deliverables

⚙️ GitHub Actions (deploy to gh-pages)

name: Deploy to GitHub Pages
on:
  push:
    branches: [main]
jobs:
  build-deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: npm ci
        working-directory: ./client
      - run: npm run build
        working-directory: ./client
        env:
          VITE_API_URL: ${{ secrets.API_URL }}
      - uses: peaceiris/actions-gh-pages@v4
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./client/dist
